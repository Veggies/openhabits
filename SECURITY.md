# Security

If you've found a security problem in OpenHabits, please report it privately rather than in a public issue.

Use GitHub's private reporting: go to the [Security tab](https://github.com/Veggies/openhabits/security) and choose **Report a vulnerability**. Include what you found, how to reproduce it, and which part it affects (an app, the server, or the directory).

You'll get a reply as soon as possible. Once it's fixed, the fix goes into a release and the report is published with credit to you, unless you'd rather stay anonymous.

Security fixes go into the latest release only.
